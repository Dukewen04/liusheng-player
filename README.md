# 留声 · Liusheng Player

一个支持多音源搜索、歌词显示、收藏与歌单管理的网页音乐播放器。前端无需安装依赖或构建，可部署到 GitHub Pages，也可在本地运行。

[打开播放器](https://dukewen04.github.io/liusheng-player/)

## 当前功能

| 区域 | 功能 |
| --- | --- |
| 歌曲搜索 | 网易云、QQ、酷我、JOOX、酷狗，默认全选；每源最多读取 5 个候选，检查后仅展示当前可播放的结果；支持直接播放、收藏和清空结果 |
| 正在播放 | 进度拖动、上一首／下一首、音量、收藏、下载入口；列表循环、单曲循环和随机播放，默认随机 |
| 歌词 | 自动查询匹配歌词，支持滚动歌词、纯文本歌词及纯净模式；备用歌词查询不阻塞播放 |
| 我的收藏 | 按歌名、歌手、专辑搜索；按歌名、歌手或收藏顺序排序；导出 JSON；清空前再次确认 |
| 自建歌单 | 新建、删除、搜索、增删歌曲、JSON 导入导出，以及一键同步到收藏 |
| 页面与恢复 | 左右面板独立收起，适配桌面与手机；记住面板状态、纯净模式、播放模式、音量及上次播放位置 |

页面采用浅色暖绿配色，歌曲搜索与我的音乐使用统一的标题、工具区、列表和按钮。桌面为三栏，平板为播放器在上、搜索与音乐在下的双栏，手机为纵向卡片布局。

搜索结果统一显示在左侧“歌曲搜索”。右侧“我的音乐”只保留“我的收藏”和“自建歌单”，两侧收藏状态同步。搜索或清空结果不会打断当前播放；清空收藏不会删除自建歌单。

## 导入歌单

点击“导入网易云 / QQ 歌单”，选择粘贴链接或导入歌单文件。

### 从平台分享链接导入

- **网易云**：我的 → 选择歌单（例如“我喜欢的音乐”）→ 分享 → 复制链接。支持 `https://163cn.tv/…` 短链接、网易云完整歌单链接，以及包含链接的整段分享文字。
- **QQ 音乐**：我的 → 我的收藏 → 分享到微信 → 用浏览器打开 → 复制链接。支持 `https://i2.y.qq.com/…` 手机分享链接及电脑端歌单链接。

请分享具体的公开歌单；个人主页、私密列表或需要登录才能读取的页面不保证能够导入。可选择同时加入收藏。

### 从文件导入

使用本播放器导出的 JSON 文件，或在导入窗口下载格式示例后整理数据。文件大小上限为 **5 MB**，读取后先显示预览，确认后才开始检查。文件内容在浏览器内解析，不上传文件本体。

导出收藏只包含收藏；导出自建歌单包含歌单数据。重新导入会合并已有内容，并根据歌曲标识去重。

### 匹配与检查规则

1. QQ 歌曲跳过 QQ 原曲取源、试播及 QQ 搜索，直接按导入的**完整歌名、歌手及版本**搜索网易云等其他音源；其他歌曲优先匹配网易云和 QQ 音乐。
2. 有可播资源就保留原歌名、歌手及已有的专辑、封面；其他音源能匹配原版本时也优先保留。合唱歌手的 `/`、`&` 等分隔符统一匹配；影视作品说明等非版本后缀可在有明确依据时归一化，现场、伴奏、混音等版本仍严格区分。音源自己的歌名和专辑另行保存，用于刷新地址，不覆盖显示信息。
3. 精确匹配失败后，先查找**同一歌手的近似歌名**：支持繁简、中文／阿拉伯数字差异，例如“17岁—刘德华”匹配“十七歲—劉德華”；也支持有界的包含关系，例如“姑娘—隔壁老樊”匹配“你的姑娘—隔壁老樊”。优先复用已有候选，缺失时才补查歌手曲目；同等级出现多个不同的相近歌名时保留原歌曲等待确认，不按音质任意挑选。备选仍需通过播放验证，并排除现场、伴奏、混音等不同版本。
4. 原版本及同歌手备选均不可播时，才尝试定位原唱，查找并验证原唱版本。不会仅因另一位歌手的音质更高而更换歌手。

近似匹配保留导入的显示名称、歌手与已有专辑信息，并显示“近似匹配：实际歌名”；实际音源名称另行保存，地址刷新和歌词查询使用匹配后的录音信息。

原唱识别目前依赖明确的原唱标注或已有原唱信息，尚未接入百科查询。没有可靠依据或信息冲突时，不猜测原唱。

导入不再跨源比较最高音质，也不提供音质优选勾选框。非 QQ 原曲可播即保留，QQ 歌曲直接搜索其他音源；需要替代时，找到并验证可播版本即可保留，不为更高音质继续查询。

### 收藏与歌单音质升级

“我的收藏”和每个“自建歌单”提供“替换最高音质”按钮，处理完整收藏或当前歌单，不受搜索筛选影响。跨源查找同歌名、同歌手、同版本候选并验证播放，只有音源标注的音质严格高于当前版本才替换；同档、较低音质、无法确认当前音质、找不到匹配或接口错误均保持原样。不使用近似歌名或原唱兜底来改变录音版本。已标明无损的歌曲直接跳过。

升级时显示总数、完成数和升级数，最多同时处理 4 首；停止保留已完成的升级，未完成歌曲保持原样。只修改点击按钮对应的收藏或当前歌单，已有其他列表和正在播放的歌曲不受影响。

开始导入后，引导窗口会关闭，单独显示进度窗口，包含总数、已完成、剩余数量，以及各歌曲的检查阶段。检查会静音验证音频开头和中段，并拒绝不足 45 秒的疑似试听资源。桌面最多同时检查 12 首，触屏设备最多 8 首；跨源选择最多同时处理 6 首。

导入候选返回并验证可播后即可保留，不必为比较音质等慢音源结束。候选详情及成功的接口查询会短时复用，故障接口短暂冷却后再尝试，其他音源继续工作；这些优化不会跳过音频检查或将错误当成可播。

完成后显示保留原曲、择优替换、已移除、未检查和暂未验证数量。接口限流、网络超时或服务故障时，歌曲标记为“暂未验证”并保留，不能据此判定为不可播或删除；重新导入可再次验证。仅在排除临时服务错误后，确认没有可播替代资源的歌曲才会移除。点击停止会保存已完成结果并保留未检查条目；刷新或关闭网页会丢失尚未保存的本次检查进度。关闭进度窗口可以继续检查，弹窗打开时背景页面不能滚动。

## 数据保存与播放限制

收藏、歌单、播放记录和设置保存在当前浏览器，不提供账号云同步。不同浏览器、设备、本地地址和线上地址之间不会自动共享；清理站点数据会删除这些内容，建议定期导出 JSON 备份。

歌曲 ID、歌名、歌手及歌单链接会在查询时发送给相应音源或解析服务。本项目不托管音乐文件，也不提供平台未开放的播放地址。

- 搜索检查只验证当前能否加载音频；导入检查会验证开头及中段，二者都不能保证整首持续可播。
- 音源返回的音质标签不代表已鉴定原始母带质量；播放地址可能过期，失败时可点击播放重试。
- 部分歌曲没有歌词，或只有无时间轴的纯文本歌词；备用歌词仍可能与具体录音版本存在差异。
- 浏览器可能限制自动播放，恢复上次位置后需要点击播放。
- 下载入口依赖音源提供的地址和浏览器行为，不保证所有歌曲均可下载。
- 手机端限制手势缩放；触控输入框使用至少 16px 字号，减少聚焦时的自动放大。

## 本地运行

需要 Python 3，无第三方依赖。在项目目录执行：

```sh
python3 server.py
```

打开 [本地播放器](http://127.0.0.1:8766/)。服务仅监听本机回环地址。macOS 也可以运行 `start-liusheng.command`，日志写入 `/tmp/liusheng-player.log`。

## 部署到 GitHub Pages

在仓库 **Settings → Pages → Deploy from a branch** 中选择 `main` 分支、`/(root)` 目录。

前端入口是 `index.html`，不需要 npm 或构建步骤；`.nojekyll` 用于直接发布静态文件。GitHub Pages 不执行 Python 或服务端 JavaScript。

网易云短链接由独立歌单解析服务展开；公开歌单列表也可通过音源接口读取。默认解析服务已经接入播放器，服务核心代码位于 `services/playlist-service.mjs`，部署前端并不等于同时部署该服务。

## 音源与可选代理

| 音源 | 当前接口 |
| --- | --- |
| 网易云 | qijieya Meting |
| QQ 音乐 | tang music API；请求串行并间隔发送，限流后暂时冷却；本地通过同源代理访问 |
| 酷我 | OIAPI；歌词按官方歌曲 ID 查询 |
| JOOX、酷狗 | apicx 公开音乐接口 |

线上默认直接访问允许跨域的音源接口。在“音源设置”可以填写兼容的 HTTPS 代理服务地址：

- `GET /api/qq?msg=歌名&mid=可选的QQ标识`：查询 QQ 歌曲或详情。
- `GET /api/playlist?url=歌单链接或分享文字`：返回可导入的歌单 JSON。

代理需允许播放器域名的 CORS 请求。歌单解析服务只接受允许的平台域名，不应扩展为任意网址转发。网络中断、接口限流或平台权限会影响读取与播放；多个音源同时失败时，检查音乐接口和音频 CDN 的网络连通性。

## 自动检查

需要 Node.js 和 Python 3，无第三方依赖。在项目目录执行：

```sh
for test in tests/*.js tests/*.cjs; do
  node "$test" || exit 1
done
node --test tests/check_playlist_service.mjs
python3 tests/check_playlist_links.py
```

检查覆盖搜索过滤、播放恢复、歌词匹配、收藏与歌单管理、导入顺序、音质降级、取消与进度、界面交互和解析服务。自动检查不能代替当前网络下的真实音源试播。
