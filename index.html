导入歌单

跟着下面的步骤，把歌单加入留声。导入会合并已有内容，不会清空收藏。

1 · 选择音乐平台

2 · 复制歌单链接

    仅能读取平台允许公开访问的歌单；私有收藏可改用歌单文件导入。QQ 支持手机分享的 i2.y.qq.com 歌单网址，线上可直接导入。网易云支持整段分享文字，163cn.tv 短链接需通过歌单读取服务展开。其他短链接请先在浏览器打开后复制歌单地址。

    3 · 确认并导入

    导入后可在“自建歌单”查看结果。重复歌曲不会重复添加；能否播放取决于音源是否提供地址。

    1 · 准备 JSON 歌单文件

    支持留声导出的 .json 收藏备份和歌单备份，也支持按示例整理的 JSON。歌曲条目包含来源、歌曲 ID、歌名和歌手。

    MP3、FLAC 是音频文件；NCM、QMC 是平台缓存文件，不能作为歌单导入。Excel、CSV、TXT 请先按示例转换为 JSON。

    查看格式示例
    {
  "version": 1,
  "favorites": [],
  "playlists": [{
    "name": "我的歌单",
    "tracks": [{
      "uid": "qq-002ITrVX0Pwgg0",
      "source": "qq",
      "songid": "002ITrVX0Pwgg0",
      "title": "等你下课(with 杨瑞代)",
      "artist": "周杰伦"
    }]
  }]
}

    source 可填 netease、qq、kuwo、joox、kugou。uid 为“来源-歌曲ID”；只填写歌名不能定位所有平台的歌曲。

    2 · 选择文件并检查

    文件本体在当前浏览器读取，不上传；检查时会按歌名和歌手查询音乐接口。请选择 UTF-8 编码的 .json 文件，最大 5 MB。

    3 · 确认导入

    检查歌曲数量后再导入。已有歌单与收藏会保留。

    逐首静音检查开头和中段。失败时搜索同歌名、同歌手、同版本的歌曲，按音源提供的音质档位从高到低试播。未找到替代时保留原曲并标记“待修复”。关闭窗口可继续检查，停止后保留已完成结果。

    待修复歌曲

      音源设置

      默认使用与 MusicSquare 相同的公开音源接口。接口无播放地址时，可以尝试其他音源；收藏保存在当前浏览器。

      配置兼容 /api/qq 和 /api/playlist 的 HTTPS 服务后，可使用代理查询和歌单链接导入。留空使用默认音源。
      新建歌单

      为喜欢的声音，留一个位置。
